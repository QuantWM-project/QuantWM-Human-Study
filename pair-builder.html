VIDEO SETUP

使用你自己的视频创建盲测

不再扫描或访问原 QuantWM 项目。直接将 MP4/WebM 视频上传到新 GitHub 仓库的 videos/ 文件夹；然后在本页填入每组视频文件名，下载 stimuli.json 并上传至新仓库根目录即可。所有文件都留在你的独立新项目中。

STEP 1 · UPLOAD TO YOUR NEW REPOSITORY

先上传视频文件

进入 QuantWM-Human-Study 新仓库 → 点击 Add file → Upload files → 上传到 videos/ 目录。首次可以通过 GitHub 网页新建 videos/.gitkeep 后进入文件夹再上传；大于 25 MiB 的文件推荐使用 Git LFS 或对象存储，而不是网页上传。

上传后的文件可以按 videos/scene01_a.mp4 访问。建议文件用不透露 QVG/QuantWM 的中性名字（如 scene01_a.mp4 和 scene01_b.mp4），减小被识别方法身份的风险。

STEP 2 · BUILD VIDEO PAIRS

配置成对视频

每行填写同一模型、相同场景、相同 prompt / seed / 动作条件下的一对视频。文件名可写 scene01_a.mp4（自动补充 videos/）或完整 HTTPS 地址。QVG / QuantWM 字段仅用于管理员配置，参与者只看到 A/B。

STEP 3 · PUBLISH

发布视频配置

下载后将 stimuli.json 上传到 新 GitHub 仓库根目录，覆盖旧文件，再刷新问卷首页。你随时能加新视频对，只需重新下载并覆盖这个配置文件，不修改投票逻辑。

注意：GitHub Pages 是静态网站，不支持浏览器把视频直接保存到 GitHub 服务器。本页负责生成配置；视频本身通过 GitHub 的 Upload files 功能上传。数据库只用于安全保存投票结果。
